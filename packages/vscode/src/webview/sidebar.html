KV Cache Type (V)
V is stored more precisely than K. The key cache is the quantization-sensitive one, so this spends memory where it helps least — prefer K at the higher precision (e.g. q8_0 K with q4_0 V).
A quantized V cache requires Flash Attention. With Flash Attention set to Off, llama-server will refuse to start — set V to f16 or put Flash Attention back to Auto/On.
